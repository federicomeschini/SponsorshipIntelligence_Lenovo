# Come chiedere un asset web (prompt di esempio)

Copia e adatta:

> Voglio creare un **[tipo di asset web: analisi one-page / minisito verticale / web report /
> presentazione a scroll / dashboard / repository]** per il brand **[OpenEconomics / Civiqa]**.
>
> Titolo: **[titolo]**. Tema: **[di cosa parla]**.
>
> Sezioni (PRETITOLO MAIUSCOLO | Titolo sentence case):
> - OVERVIEW | Il quadro d'insieme
> - [...]
>
> Materiali: allego **[Excel / PDF / testi / immagini / logo]**.
> [Se analisi/dashboard:] i dati sono in **[file]**; i KPI principali sono **[...]**.
> [Se web report:] usa i testi **verbatim** dal documento allegato.

Più sei specifico su sezioni, dati e materiali, migliore è il risultato.
