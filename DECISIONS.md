# Decision log

Append-only ADR log for choices not fixed by `ARCHITECTURE.md`.

## ADR-0001 — Preserve client exports as immutable raw inputs

- **Context:** The repository initially contained two XLSX survey exports and one CSV exposure export. The architecture requires immutable raw data and reproducible downstream staging.
- **Decision:** Keep the supplied files in their original formats under `data/raw/`, grouped by source, and use descriptive filenames. Connectors may later emit typed parquet to `data/staged/`; raw files must not be edited in place.
- **Alternatives:** Convert the files immediately to parquet; retain the original flat root layout.
- **Consequences:** Source fidelity is preserved and the input provenance is clear. The first ingestion implementation must handle XLSX/CSV and produce manifests and typed staged artifacts.

## ADR-0002 — Keep unresolved client-dependent inputs as templates

- **Context:** The architecture requires event metadata, property taxonomy, ticker mapping, and a royalty schedule, but those inputs were not present in the initial workspace.
- **Decision:** Add schema/header templates with no invented business values. Populate them only from approved source data and log the resulting choice here.
- **Alternatives:** Infer event dates and taxonomies from filenames or external knowledge.
- **Consequences:** The repository is structurally ready while L5/L6/L7 remain correctly blocked until the missing inputs are supplied.

## ADR-0003 — Use NASDAQ-100 converted to HKD as the global technology factor

- **Context:** O-02 requires a reproducible global technology factor. MSCI ACWI IT history generally requires a licensed feed, while NASDAQ-100 and USD/HKD are available through the selected public endpoint.
- **Decision:** Use NASDAQ-100 (`^NDX`) converted to HKD with `HKD=X`; retain Hang Seng (`^HSI`) as the local market factor. Store source prices separately and perform currency conversion in L5.
- **Alternatives:** License MSCI ACWI IT; use unconverted NDX; use a technology ETF.
- **Consequences:** L5 can be prototyped reproducibly. NDX's concentration and US-market tilt must be disclosed, and a licensed factor can later replace it through the same contract.

## ADR-0009 — Activate the automated anonymous_web Trends backend (supersedes ADR-0007's blocked state)

- **Context:** ADR-0007 left D3 blocked, attributing the anonymous endpoint's HTTP 429 to a shared egress IP and requiring 90 manual UI exports. Re-testing from the local residential host showed the 429 was only partly IP-related: the raw `/api/explore` call is rejected because it carries no session cookie, and the `/api/widgetdata/multiline` call throttles intermittently.
- **Decision:** Implement the `anonymous_web` backend already named in `backend_order`. The client seeds the `NID` cookie by first requesting the explore page (which itself may 429 while still setting the cookie), reads the `TIMESERIES` widget token, then fetches the multiline series with bounded retry/back-off. `pull_trends(backend=...)` supports `auto` (manual exports win when present, else anonymous), `manual`, `anonymous`, and `probe`. Raw multiline JSON responses are persisted per draw as immutable provenance.
- **Draw definition (revised):** The original ten-rapid-draws-then-average design does not work against this endpoint: identical requests fired seconds apart return byte-identical cached series, so between-draw variance is zero and the average equals a single pull. We therefore implement W-01's other prescribed mechanism — overlap-ratio window rescaling. Draw 0 is the full-horizon weekly reference; the remaining `draws_per_query - 1` draws are overlapping sub-windows (`window_fraction` of the span, floored so Trends still returns weekly) each rescaled onto the reference by the ratio of summed interest over their unsuppressed overlap (`min_overlap_weeks` guard). Stacking the rescaled draws makes `interest_mean` robust to any single normalising peak week, and `interest_sd` now measures genuine normalisation instability rather than sampling noise.
- **Alternatives:** Keep requiring 90 manual exports; wait for official closed-alpha credentials; adopt `pytrends` or a paid scraper; keep rapid-repeat draws (rejected — degenerate variance); add a fine 90-day daily granularity splice (deferred — weekly is sufficient for L1).
- **Consequences:** A W-01-compliant curated worldwide Trends series is produced automatically, without manual exports or API credentials. `interest_sd` is small where a query's worldwide salience is normalisation-stable and wider for spiky event-driven co-brand queries, which is the intended diagnostic. The series still depends on an unofficial endpoint that Google may change or throttle, so the manual-export path and queue remain the audited fallback. The manual parser recognises English UI headers only; non-English exports (e.g. an Italian `Settimana` export) must be re-exported in English or ingested via the automated backend.

## ADR-0010 — Query design adequacy pass against §3.3 objectives

- **Context:** A review of `queries_trends.yaml` against the LOCKED §3.3 family objectives found the families structurally present but three adequacy gaps: (1) the category-purchase family used bare product names (`ThinkPad`, `Lenovo Legion`) that proxy salience, not the consideration/intent the commercial pillar requires; (2) no synthetic-control donor queries existed, though O-05/L6 require competitor Trends series; (3) the brand family's `target_pillar` was `awareness`, which is not one of the five `survey_pillars`.
- **Decision:**
  - **Category-purchase:** retain the three product-name queries as candidates and add commercial-intent modifiers (`Lenovo laptop price`, `ThinkPad price`) so the family genuinely proxies intent per the §3.3 example.
  - **Competitor donor family (new, `role: scm_donor`):** add Dell, Asus, Acer (clean computing brands, bare term), plus `HP laptop` and `Samsung laptop` (raw terms ambiguous / phone-dominated → PC-line per O-05) and `Huawei` (flagged `quality_flag: low` for phone/telecom and CN-brand coverage per W-09). These are candidates for L6 donor screening, not Lenovo funnel-stage proxies; the `role` field lets §5.2 validation skip them.
  - **Brand stage label:** ~~change the prior from `awareness` to `media`~~ **superseded by ADR-0011** — pillars were removed; the brand family's `target_stage` is `awareness` (a funnel stage). All final stage assignment remains empirical (§5.2).
  - **Co-branded family:** left unchanged. The `Lenovo X` conjunction is the correct construct for property-attributed salience; broadening to bare property terms would measure the property's own salience, not Lenovo's. The `esports` property (named in D2) is not added because no client-confirmed co-branded term exists (ADR-0002 — no invented business values).
- **Alternatives:** Replace product-name queries entirely (rejected — they are valid candidates); build donors as bare brand terms (rejected — ambiguity per O-05); pull donors in a separate config (rejected — same W-01 treatment needed, one config is simpler).
- **Consequences:** The query set grows from 9 to 17 (brand 1, category 5, co-branded 5, donor 6); the pull produces 170 draws. `composition_id` stays `worldwide_v1` (geo composition unchanged). Downstream proxy validation (§5.2) and any funnel-stage/property consumer must filter on `role` so donor and outcome series are not conflated. Co-branded property salience remains sparse (most weeks `<1`), a documented measurement limit on the L4b identification core that compounds with the unavailable Blinkfire engagement rate (ADR-0005); whether property salience is measurable in Trends at all is a client-facing decision, not resolved here.

## ADR-0011 — Replace the five brand pillars with the client's marketing funnel; construct a non-canonical wave anchor from the client waves

- **Context:** The architecture assumed the D1 survey delivered a composite plus five brand *pillars* (media, digital, institutional, commercial, experience). Inspection of the actual client waves shows this is wrong and will never hold: the client measures a marketing **funnel**. The two client survey exports are both D1 waves — the GWI export provides population-level quarterly **engagement** and **consideration** (Q1 2017–Q1 2026), and the consumer-research crosstabs provide **awareness**, **appeal**, and **purchase_intent** (segmented by sponsorship awareness, 2024–2026, with a 2024→2025 response-scale break). The assumed composite+pillar analytical extract is not coming.
- **Decision (funnel replaces pillars, everywhere):** The canonical brand construct is the ordered funnel `awareness → engagement → appeal → consideration → purchase_intent`. `survey_pillars` becomes `survey_funnel` (base.yaml); `PILLARS`/`target_pillar` become `FUNNEL_STAGES`/`target_stage` in code and config; ARCHITECTURE §3.2/§3.3/§4/§5.2, the reports, and the anchor template are reworded to funnel stages. `composite` is retained only as an optional overall roll-up (no longer a PCA-of-pillars); the anchor no longer requires it. This supersedes the pillar terminology in ADR-0006 and ADR-0010 and the pillar model in the architecture.
- **Decision (constructed anchor):** Because no approved analytical extract exists, `survey_anchor.py` gains `construct_wave_anchor`, which builds a **non-canonical** anchor from the client waves: the GWI quarterly series populate `engagement` and `consideration`; fieldwork dates are set to quarter boundaries with the midpoint as the anchor point (a documented approximation of GWI's continuous fielding); `awareness`/`appeal`/`purchase_intent` are left null in the population anchor because the crosstab values are sponsorship-segmented and scale-broken, not population wave scores. Every row carries `canonical_anchor_eligible: false`, and a deviations register records each departure from the anchor contract. The canonical path (`ingest_survey_anchor`) and its blocked status remain for when the client supplies an approved extract.
- **Alternatives:** Adopt GWI directly as the index target with no anchor artifact (rejected — less reusable, no deviations trail); fold the crosstab awareness/appeal/intent into population scores (rejected — they are segment-conditioned and scale-broken, so that would fabricate population values); keep pillars and wait (rejected — they do not exist).
- **Consequences:** L2 can prototype on a usable-but-caveated two-stage funnel anchor (engagement, consideration) now, with three stages pending a proper population extract. Any index/attribution built on the constructed anchor must carry the non-canonical caveat and must not be presented as the client-approved Brand Index. The funnel is an ordered sequence, not a factor structure, so the architecture's PCA-composite and LMG-attribution specifics are superseded and will be redefined when L2 is built.

## ADR-0012 — Consumer-research crosstab enters as a sponsorship-lift companion, not as a population index anchor

- **Context:** We tested whether the consumer-research crosstab (awareness/appeal/purchase_intent, split by FIFA-sponsorship Aware/Unaware, per property, 2024–2026, scale-broken) could populate the population funnel anchor. It has no weighted population total, and the guardrail forbids recombining segments with the unweighted `Column n`. A GWI-calibrated weight was attempted — solve `w` so `w·aware + (1−w)·unaware` matches the GWI population level — but it is **degenerate**: implied `w` is negative in every wave (−0.90, −0.17, −0.24) because GWI general-population Lenovo consideration (~11%) sits below even the sponsorship-unaware FIFA-context intent (~18–37%). The constructs and contexts are not on a shared scale, so no valid population total can be recovered.
- **Decision:** Keep the GWI stages (engagement, consideration) as the population brand-index anchor. Do **not** fold the crosstab into the population anchor. Instead add a companion artifact, `sponsorship_funnel_lift`, = `aware − unaware` per funnel stage × property × wave. Differencing cancels the within-wave response scale, so the lift is comparable within a wave even where the levels are not. Both segments are retained in the artifact.
- **Alternatives:** Unaware-segment-as-baseline (rejected — discards the aware signal); unweighted midpoint (rejected — fabricates a ~50%-aware assumption); GWI-calibrated weight (rejected — degenerate, see Context).
- **Consequences:** The index stays a clean population measure while the sponsorship dimension is preserved as an explicit lift layer. The lift is **observational, not causal**: sponsorship-aware respondents self-select, so the gap upper-bounds the true effect (causal estimation is the job of the L4b panel / event study / SCM stack, W-04); the artifact is flagged `is_causal_effect: false`. The **awareness** lift is near-mechanical (the aware segment is ~100% brand-aware by construction); the **appeal** (+33 to +48pp) and **purchase_intent** (+28 to +41pp) lifts are the substantive signals.

## ADR-0013 — Single Brand Index: PCA composite (Tier A) + state-space signal fusion (Tier B); reinstates a composite

- **Context:** ADR-0011 deferred a composite, arguing the funnel is an ordered sequence, not a factor structure. That was too dismissive: a brand index is conventionally a single value, and the funnel stages are highly correlated (they move together), so a first principal component is a well-behaved composite. A single index is required for the L1→L7 spine.
- **Decision (Tier A composite):** `srmp/index/composite.py` aggregates the populated funnel stages into one quarterly Brand Index via PC1 of the standardized stages, oriented so higher = stronger, on a mean-100/sd-15 scale. With the two GWI population stages, PC1 loadings are 0.71/0.71 and explain 98.7% of variance (≈ standardized average); it becomes a genuine multi-stage PCA when awareness/appeal/purchase_intent gain population extracts.
- **Decision (Tier B final weekly index = state-space fusion):** `srmp/index/statespace.py` (the architecture's `v2_statespace`) is the final weekly index. A single latent weekly brand state follows a random walk; every signal is a standardized noisy observation `obs = x_t + e`, with observation variance encoding trust — **survey waves are the priority signal (var 0.08), admitted proxies are secondary (var 0.40, ~5× looser)**. The proxy variance is tuned so the weekly Trends texture actually passes through between waves (an earlier 20× ratio over-smoothed the index into quarterly interpolation with no weekly movement); at 5× the survey still pins the level while the proxy drives the weekly path. A Kalman filter + RTS smoother fuses them: the index is pinned at survey-wave weeks (SE ≈ 2.5) and follows the admitted Trends proxies between waves (visible weekly movement, wider band). This subsumes the Tier-A composite (loadings aggregate the stages) and Chow-Lin (temporal fill) in one coherent model. Chow-Lin (`v1_chowlin`) is retained as the simpler single-indicator alternative (consideration built, pass-through error 3e-17).
- **Signals fused (level index):** GWI engagement + consideration and consumer-research **awareness** (unaware baseline, consistent binary scale) as priority; the mean-z of the six admitted Trends proxies as the secondary high-frequency signal. **Appeal and purchase_intent are excluded from the level fusion** because their 2024→2025 scale break makes levels non-comparable; they remain in the sponsorship-lift companion (ADR-0012) and will re-enter when consistent-scale versions exist.
- **Alternatives:** Disaggregate each stage separately then combine (rejected — composite-then-disaggregate is cleaner and matches Tier A); equal-weight average (kept implicitly — PC1≈average at two stages); admit all proxies regardless of the gate (rejected — P4; wrong-sign Wikipedia/GDELT stay out).
- **Consequences:** A working, provisional single weekly Brand Index exists (2022–2026, 235 weeks), honestly uncertainty-banded and anchored to the client's survey waves. It is **non-canonical** (GWI-based anchor, ADR-0011) and must not be presented as the client-approved Brand Index. When the approved analytical extract arrives, the same pipeline runs canonically by swapping the anchor. *(Signal construction and tuning superseded by ADR-0014 — the var-0.40/hand-tuned-q parameterisation and the awareness signal produced a mis-levelled index.)*

## ADR-0014 — Level-coherent state-space index: full-history standardization, proxy level calibration, MLE process variance; awareness excluded from the level fusion

- **Context:** The v2 state-space index contradicted its own anchor. At the 2026Q1 wave week it read **121.5** (peaking at **140.5** in May 2026, z ≈ +2.7 "all-time high") while the Tier A composite — the survey itself — read **92.2** (below the long-run average). Four construction defects compounded: **(1)** survey stages were z-scored *after* truncating to the 2022+ grid window, so the level relative to the full 2017–2026 anchor was destroyed (2026Q1, below the long-run mean, became the *top* of the depressed window); **(2)** the proxy composite entered in its own-history z-units with loading 1, so its arbitrary level/amplitude steered the index — the June-2026 World Cup search surge (proxy z +3.3) was read as a brand-*health* boom; **(3)** the process variance q was hand-fixed at ~0.3 (the ADR-0013 "texture" tuning), so survey information decayed within a week or two and wave weeks became one-week spikes; **(4)** the crosstab awareness signal averaged FWC/FWWC/CWC unaware-awareness per week (its movement was mostly *which property was surveyed*: FWC ~0.52–0.53 vs FWWC ~0.38–0.45) and z-scored ≤5 points on their own sd, so a 1.4pp move entered as ±1σ with survey-grade trust. The published artifact also recorded parameters (proxy var 0.25, q 0.3) the code could not produce — an unreproducible ad-hoc run.
- **Decision:** `srmp/index/statespace.py` rebuilt for level coherence. **(a)** Survey stages standardized over the **full anchor history**, then sliced to the grid — the weekly index now shares the Tier A composite's mean-100/sd-15 meaning. **(b)** The proxy composite is **affine-calibrated onto the anchor scale** by OLS of wave-week survey z on proxy z (17 waves; fitted slope 0.11, so a +3σ salience spike moves the level ~0.33σ); its observation variance is the calibration residual variance floored at 1.5× the survey variance; a proxy with thin overlap or non-positive slope is excluded. **(c)** q chosen by **MLE over a bounded grid** (selected 1e-4, interior), so anchor information propagates between waves. **(d)** The crosstab awareness signal is **excluded from the level fusion** (composition artifact + own-sample scale; it stays in the sponsorship-lift companion, ADR-0012) — it may re-enter when a per-property series has enough waves (≥6) on a consistent scale, calibrated like the proxy. Artifacts regenerated via the CLI so manifest and code agree; the manifest now records the calibration and the q-selection mode.
- **Alternatives:** Keep window standardization and rescale the output (rejected — hides the defect, still incoherent with Tier A); keep hand-tuned q for visible weekly "texture" (rejected — the texture was fabricated level movement; the honest weekly path is smooth because the proxy demonstrably carries little level information); drop the proxy entirely (rejected — calibrated, it contributes honest between-wave information and sets the grid span).
- **Consequences:** At every survey wave week the v2 index now sits within 3 points of the Tier A composite (mean gap 1.3); spring 2026 reads ~90–91 (below long-run average, slowly recovering), not 140. Weekly movement between waves is small — that is the honest message: the admitted search proxies explain little of the anchor's level variation, so the weekly index is mostly smooth interpolation with narrow bands. A regression test (`test_statespace_level_coheres_with_tier_a_composite`) now fails the build if the two Brand Index artifacts diverge at wave weeks. Any report or figure citing the previous 120–140 levels for 2026 must be regenerated.

- **Context:** Google Trends is now available for the full 2022–2026 horizon.
  The Chow–Lin and state-space builds attempted to manufacture weekly brand
  equity by forcing sparse, non-canonical survey observations through latent
  interpolation models. A later proxy-led build pooled parent-brand and product
  queries, but that pooled signal failed a four-quarter temporal holdout against
  simply carrying forward the last survey observation.

  `v4_proxy_led_brand_calibrated`. Worldwide Trends for the exact `Lenovo`
  parent-brand query supplies all weekly movement. The GWI
  engagement/consideration PC1 supplies only orientation and display-scale
  calibration. The index is explicitly a Lenovo **brand-salience index**, not a

## ADR-0016 - Treat the Lenovo Brand Index as descriptive, not a forecast model

- **Context:** ADR-0015 used a last-four-quarter forecast-style holdout as a publication gate. That is the wrong criterion for the current purpose: the weekly Lenovo Brand Index is a descriptive construct, not a model intended to forecast a future GWI wave. The gate risked selecting components for short-horizon extrapolation rather than construct validity. It also obscured the meaningful choice between a survey-neutral PCA composite and an evidence-weighted composite.
- **Decision:** Forecast or nowcast exercises may be retained as separate research diagnostics, but cannot accept, reject, or select C-INDEX. The current canonical simple index remains the parent-brand Lenovo Trends salience series, GWI-calibrated only for orientation and display scale. Two Lenovo-only multi-signal alternatives are documented: PCA (common movement across salience, product portfolio, commercial intent, and earned-news tone) and evidence weighting (non-negative, sum-to-one ridge weights fitted to the same four dimensions against GWI). Evidence weighting uses a fixed ridge penalty of 5.0 as a strong-shrinkage governance rule, not a forecast-tuned hyperparameter. All three methods report survey convergence and leave-one-quarter-out weight sensitivity.
- **Alternatives:** Continue to choose the index by temporal holdout (rejected: it changes the target from measurement to forecast); make GWI a weekly anchor (rejected: sparse waves do not measure every week); include peer position (rejected: benchmarking is not Lenovo brand performance).
- **Consequences:** Current manifests contain no forecast pass/fail field. A non-positive calibration slope, unstable signs, or material dependence on a single GWI quarter triggers review before publication. The crosstab survey remains a sponsorship-lift companion, not a population calibration target. This supersedes ADR-0015's temporal-holdout validation and publication gate.

## ADR-0017 - Isolate the sponsorship-to-monetization bridge as an experimental path

- **Context:** The Brand Index, observational aware-minus-unaware funnel lift, and confirmed Blinkfire impressions/views can now be connected conceptually, but the workspace is not a Git repository and the evidence is insufficient for a causal exposure-lift regression or monetary ROI. Only five 2025-plus property-wave observations have comparable survey scales and preceding exposure coverage. The approved royalty schedule, attributable Brand Index change, brand-attributable revenue, fee, discount rate, and persistence horizon are absent.
- **Decision:** Implement `sponsorship_monetization_v1` under isolated experimental code, config, and curated-output namespaces. It cannot replace C-INDEX, C-EXPOSURE, or C-ROI. Appeal and purchase-intent lift are averaged within property-wave; awareness is excluded as mechanically related to segment definition. Impressions receive fixed scenario adstock delta 0.80 and are aligned over the 13 weeks ending at reported month-end because exact fieldwork dates are unavailable. The property allocation scenario is proportional to each property's mean across survey waves of trailing-adstock exposure times positive funnel lift. This share may distribute an independently identified total effect but cannot create or identify that effect. Monetary rows are emitted only if every explicit valuation input is populated.
- **Alternatives:** Put survey lift into Brand Index weights (rejected: different construct and selected segments); estimate a fixed-effects exposure-lift model on five observations (rejected: not credible); populate valuation inputs with assumed business values (rejected: commercially indefensible); allocate using full-period exposure (rejected: leaks later exposure into earlier survey evidence).
- **Consequences:** A reproducible attribution bridge and executable royalty-relief gate now exist. Current property shares are scenario diagnostics, not causal value shares. No monetary result is produced in the current run, and canonical artifacts remain unchanged. The experiment must be re-estimated when exact fieldwork dates, additional comparable waves, broadcast exposure, a defensible counterfactual Brand Index change, and approved valuation inputs become available.

## ADR-0018 - Implement but do not accept the first synthetic-control attribution candidate

- **Context:** Five base donor Trends series cover the complete pre/post period, so an experimental Lenovo synthetic control can be fitted around the 2024-10-15 FIFA partnership announcement. A positive point estimate is not sufficient for monetization; it must be distinctive relative to donor and time placebos. The royalty schedule remains pending with no approved Index/rate points.
- **Decision:** Fit non-negative sum-to-one donor weights with all standardization frozen before the first full post week, 2024-10-21. Use Dell, Asus, Acer, HP laptop, and Samsung laptop as base donors; keep Huawei sensitivity-only. Convert the synthetic gap to canonical Index points, report unweighted and FIFA-digital-exposure-weighted gaps, and run donor, fake-date, leave-one-donor-out, and Huawei-inclusion diagnostics. The monetization bridge may use the candidate automatically only when the experimental pre-fit and placebo screens pass and configuration explicitly opts in. Implement a piecewise-linear royalty resolver requiring at least two approved Index/decimal-rate points and prohibit extrapolation.
- **Result:** Pre RMSPE is 0.305 Index points and the exposure-weighted candidate is +0.892 points, with donor-set range +0.618 to +1.431. The donor-placebo p-value is 0.833, so the candidate status is `candidate_not_distinguishable`; it is not used for valuation. The royalty resolver is operational but blocked because `config/royalty_schedule.yaml` has status `pending_client_calibration` and zero points.
- **Consequences:** The counterfactual estimate is preserved as sensitivity evidence, not a causal central case. Monetary output remains empty. Accepting a non-zero Index attribution requires stronger donor/placebo evidence or an alternative identified design; resolving royalty bps requires an approved schedule or external comparable-royalty calibration.

## ADR-0019 - Make the World Cup the primary prospective sponsorship evaluation

- **Context:** The greatest Lenovo sponsorship impact may occur during the World Cup, whose complete exposure, post-event Index, survey, and persistence data are not yet available. The 2024-announcement/FCWC synthetic control is an interim diagnostic and fails its donor-placebo screen. Waiting to choose the World Cup method after observing the outcome would create researcher degrees of freedom around dates, donors, transformations, and windows.
- **Decision:** Preregister `world_cup_impact_v1` now as the primary sponsorship impact evaluation. Freeze an exposure-weighted actual-minus-counterfactual Brand Index gap as the primary estimand, with at least thirteen post-tournament weeks; keep all-post, peak-four-week, persistence, co-brand search, and survey lift as secondary outcomes. Require jointly scaled anchored Trends panels, at least nine credible donors, 104 pre weeks with a final 26-week validation holdout, augmented SCM with simplex SCM and synthetic-DiD robustness, product-launch controls, donor/time placebos, and placebo p-value at most 0.10. Prohibit post-outcome tuning. Approved event dates remain null until supplied rather than inferred from outcome peaks.
- **Alternatives:** Treat the 2024 announcement as the final intervention (rejected: likely misses the largest activation); reuse the current five independently normalized donors (rejected: weak placebo resolution and measurement coherence); tune the model after World Cup data arrive (rejected: biases attribution); require broadcast data before any counterfactual estimate (rejected: broadcast is essential for total-exposure interpretation but not logically required to estimate an Index gap).
- **Consequences:** The skeleton emits readiness and preregistration manifests now and zero accepted attribution rows. The existing counterfactual remains interim. Only a World Cup estimate passing the frozen gates may enter the monetization `delta_index_attrib`; royalty calibration and BCF-adjusted revenue remain separate gates.

## ADR-0020 - Separate brand counterfactual donors from sponsorship exposure controls

- **Context:** A property-level pilot used Lenovo-F1, Lenovo-MotoGP, and Lenovo-Ducati co-search as synthetic donors for Lenovo-FIFA co-search. That can probe a property mechanism, but sponsored properties cannot represent Lenovo's missing no-FIFA Brand Index. Blinkfire exposure is also treatment intensity and would create circular identification if used to construct the untreated outcome.
- **Decision:** Keep the Brand Index counterfactual at the competitor-brand level. Dell, Asus, Acer, HP laptop, and Samsung laptop remain provisional base salience donors; Huawei remains sensitivity-only. Record their treatment-contamination status in a donor registry. Aggregate all FIFA-taxonomy Blinkfire rows into `A_fifa` and all other Lenovo sponsorship rows into `A_nonfifa` only after synthetic weights are fitted. Use `A_fifa` to exposure-weight the gap and both series in a HAC timing regression labelled descriptive, never causal. Retire `fifa_property_synthetic_v1` from the Brand Index and valuation paths while preserving it as a mechanism diagnostic.
- **Alternatives:** Use Blinkfire properties as Brand Index donors (rejected: wrong unit and treatment circularity); require donors that have never sponsored anything (rejected: unnecessary and likely destroys comparability); drop other sponsorship exposure (rejected: it is a useful negative control for Lenovo-wide activation timing).
- **Consequences:** The candidate gap remains +0.892 Index points and still fails the donor-placebo screen (p=0.833), so monetization remains blocked. The FIFA timing coefficient is +0.276 Index points per standard deviation of log adstock (HAC SE 0.104), but only as association. The World Cup design still needs at least nine jointly scaled donors, full treatment-contamination screening, product/campaign controls, broadcast exposure, and future outcome data.

## ADR-0021 - Expand, jointly scale and screen the brand donor pool

- **Context:** ADR-0018/0020 used five separately normalised Trends donors and left three documented gaps: at least four additional donors on one scale, a traceable FIFA-treatment screen, and Lenovo product/campaign controls. Samsung subsequently showed outcome-contaminating FIFA+/World Cup activity, and several newly collected terms were too sparse for weekly SCM.
- **Decision:** Replace independently normalised donor inputs with six Google Trends panels linked by a repeated Lenovo anchor, ten draws per panel and positive-overlap multiplicative scaling. Screen 21 candidates over 2022-01-01 to 2026-07-15 using FIFA rosters/annual reports, commercial announcements and targeted brand searches. Use 11 clean base donors: Dell, Asus, Acer, HP laptop, Microsoft Surface, Razer, Logitech, MacBook, Corsair, SteelSeries and BenQ. Keep Huawei and MSI sensitivity-only; exclude Samsung and LG gram for contamination and six sparse/constant queries for data quality. Add 21 Lenovo event rows and one-week carryover controls; classify 2024-10-15 as mixed FIFA and Tech World news. Negative searches mean no match in the recorded sources/window, not proof of permanent absence.
- **Result:** Pre RMSPE improves to 0.244 Index points. The exposure-weighted candidate is +1.033 points (event-week-excluded +1.021), and donor-placebo p=1/12=0.0833 passes the registered 0.10 screen at its finite-sample boundary. However, after FIFA/non-FIFA exposure, time and event controls, the FIFA timing coefficient is -0.144 (HAC SE 0.160), so timing coherence is not supported.
- **Consequences:** The three input-development gaps are closed and the World Cup readiness skeleton now waits only for milestone dates, updated World Cup exposure and its exact event calendar among required estimation inputs. The interim candidate is still not accepted or monetised: the primary World Cup outcome is incomplete, controlled timing is unsupported, broadcast and campaign intensity are missing, and valuation still lacks an approved royalty schedule and BCF-adjusted revenue inputs. ADR-0021 supersedes the provisional donor composition and empirical results in ADR-0018/0020 without erasing their historical record.

## ADR-0022 - Isolate an official-calendar World Cup exposure simulation

- **Context:** The official match calendar and about 87.5% of tournament-period Trends outcomes are available, while World Cup Blinkfire and persistence data are not. A test simulation can exercise the design, but simulated exposure must not be mistaken for observed treatment or used to manufacture attribution.
- **Decision:** Pull and snapshot FIFA's public API calendar for competition 17/season 285023 and require all 104 matches. Generate low/base/high weekly exposure profiles from fixed stage weights, calibrated respectively to the p90, maximum, and 1.5 times maximum of 64 positive historical Lenovo FIFA-family Blinkfire weeks. Mark every row simulated and isolate all outputs under `world_cup_simulation_v1`. Report two counterfactuals: the frozen pre-announcement no-partnership path and a pre-tournament-refitted continuation that estimates incremental World Cup lift above the existing sponsorship baseline.
- **Result:** Through 5 July, 91/104 matches and five Index weeks are observed. The base simulated weighting gives +0.367 Index points against the old no-partnership path but -0.160 points for incremental tournament lift. The latter has p=0.333, pre RMSPE 0.380 and 26-week holdout RMSPE 1.157.
- **Consequences:** The simulation currently provides no evidence of a positive incremental tournament effect and produces no accepted or monetary row. Its main value is operational: the official calendar, exposure schema, dual estimands and replacement path are ready for real Blinkfire. The primary preregistration remains waiting for observed exposure, final/persistence outcomes and the remaining mechanism inputs.

## ADR-0023 - Use direct profit as the financial outcome and stock only as corroboration

- **Context:** Monetising a Brand Index point through the stock-price level would confuse market expectations with realised profit and violate the architecture's return-only financial guardrail. Lenovo publishes quarterly revenue and adjusted/non-HKFRS net income, while the workspace contains daily Lenovo, HSI, Nasdaq-100 and USD/HKD prices.
- **Decision:** Build `brand_financial_bridge_v1` from 16 official Lenovo quarters covering FY22/23 Q1 through FY25/26 Q4, using later officially restated adjusted-profit comparatives where available. Make adjusted net-income margin the primary outcome. Estimate first-difference models with HC3 uncertainty and category-demand, HSI, Nasdaq-100-in-HKD and fiscal-season controls; add revenue growth in the profit-growth sensitivity. Convert stock prices to factor-adjusted returns using HSI and lagged Nasdaq-100-in-HKD, then use weekly abnormal-return association only as corroboration. Apply the controlled coefficient mechanically to current Index cases but force all rows to unaccepted.
- **Result:** The primary estimate is +0.0035 adjusted-margin percentage points per Brand Index point, SE 0.5016, interval -0.9796 to +0.9866, p=0.994. At US$21.588bn quarterly revenue this is +US$0.75m per quarter, with an interval of -US$211.48m to +US$212.98m. Margin specifications range from -0.788 to +0.196 points and change sign. Weekly abnormal return is -0.873 percentage points per Index point, SE 0.821, p=0.287.
- **Consequences:** No empirical BI-to-profit coefficient is approved for valuation. The uncontrolled positive relationship is absorbed by category and market controls, and the remaining sample has only 15 first differences. Decision-grade monetisation still requires an accepted sponsorship Index effect plus a separately identified BCF/profit base or approved royalty-relief schedule; the new bridge is a transparent reasonableness and data-requirements diagnostic.

## ADR-0024 - Rebuild the stock response without look-ahead and add direct income valuation

- **Context:** The first stock sensitivity used a full-sample factor model, raw Index changes and no explicit Lenovo financial-results control. It was therefore too weak to serve even as clean market corroboration. L7 also described relief from royalty as if it were the only income route, while ISO 10668 permits an income framework and IVS 210 identifies excess-earnings, relief-from-royalty, premium-profit and with-and-without methods.
- **Decision:** Create stock_brand_response_v2. Estimate each daily expected Lenovo return from the preceding 120 trading days using HSI and the latest Nasdaq-100-in-HKD return available before Hong Kong trading. Define a Brand Index innovation from a prior-only 104-week rolling model with a 52-week minimum. Estimate cumulative abnormal-return responses at frozen 0, 1, 4 and 13-week horizons with category, campaign, promotion, mixed-event, volatility and all 16 official results-release controls. Use overlapping-horizon HAC uncertainty, Holm family-wise adjustment, a future-Innovation placebo, leave-one-quarter-out tests and fixed endpoint stability. Expand L7 so the primary direct route is discounted with-and-without incremental free cash flow when operating inputs exist; retain royalty relief as a cross-check and MPEEM as an alternative only with contributory asset charges.
- **Result:** The immediate response is +0.305 abnormal-return percentage points per unexpected BI point, interval -0.817 to +1.427, p=0.594. The 13-week estimate is +9.403 points with raw p=0.043 but Holm p=0.171. It changes from -2.822 through 2024 to +2.773 through 2025 and +9.403 in the full sample, so it is endpoint-sensitive to the 2026 rally. No frozen horizon survives family-wise testing.
- **Consequences:** The stock model is now operational and auditable but supplies no approved profit or causal valuation coefficient. A future accepted stock response could map to equity value using dated market capitalisation; converting that value to a cash-flow equivalent would additionally require WACC, growth and persistence assumptions. Decision-grade sponsorship value should instead come from identified differences in price, volume, retention/service, costs, tax and working capital between with- and without-sponsorship forecasts, after the World Cup outcome is complete.

## ADR-0025 - Accept a positive market-implied earnings calibration for planning

- **Context:** Most product-level price, margin, retention, WACC and royalty inputs requested by a full income valuation are unlikely to be obtainable. Requiring them leaves the sponsorship model without an operational monetary number. The corrected immediate stock-response coefficient is already positive, and Lenovo publishes adjusted earnings, shares and market capitalisation.
- **Decision:** Select the immediate response of +0.305171% abnormal equity return per unexpected BI point. Under a constant observed earnings multiple, translate the same percentage into market-implied annual adjusted earnings. Use Lenovo FY2025/26 adjusted net income of US$2.049bn and cross-check against the official 31 March 2026 market capitalisation of approximately US$14.5bn and its 7.08-times adjusted-earnings multiple. For commercial planning only, impose beta_planning=max(0,beta_empirical), retaining the unconstrained interval and tests in the evidence artifact.
- **Result:** One BI point maps to +0.305171% or +US$6.253m annual adjusted earnings-equivalent. The positive planning range is US$0 to US$29.244m per BI point. The +1.033 announcement candidate maps mechanically to +US$6.461m per year.
- **Consequences:** The calibration is accepted for planning and no longer blocked by inaccessible client data. It is not an audited profit forecast or causal estimate. Sponsorship attribution remains a separate gate: a positive coefficient cannot make an unaccepted BI counterfactual causal. A future operating-data income approach can supersede this fallback without changing the documented stock-response evidence.

## ADR-0026 - Replace the single BI multiplication with a dynamic total-return model

- **Context:** Applying the +0.305% immediate stock coefficient to the +1.033 exposure-weighted average BI level gap produced US$45.7m and was labelled total sponsorship value. That mixed a coefficient estimated on weekly unexpected BI changes with an average level, used a stale March 2026 market capitalisation and ignored response maturation, incomplete Men's World Cup coverage and the 2027 Women's World Cup.
- **Decision:** Translate the weekly actual-minus-synthetic gap into sponsorship BI innovations using the rolling lag coefficient from the Index innovation model. Convert the frozen 0/1/4/13-week cumulative stock responses into a nonnegative monotone distributed-lag curve. Use estimates through 31 December 2025 for the base response so the World Cup rally cannot determine its own value; retain the immediate full-sample response as low and the complete full-sample curve as high. Value fully matured attributable log returns against the 14 July 2026 market capitalisation. Project the remaining Men's calendar from its observed 87.5% coverage and represent the 2027 Women's World Cup as 25/50/75% of the Men's effect in low/base/high scenarios. Keep announcement and tournament CARs as non-additive confounded triangulation.
- **Result:** The observed BI path has 0.730 aligned sponsorship innovations. Fully matured observed-path values are US$81.6m, US$734.7m and US$2.432bn. Full-contract planning values are US$116.5m, US$1.250bn and US$4.702bn. Announcement CARs imply US$306m-US$756m; the tournament-period gross CAR implies US$4.014bn but is materially confounded.
- **Consequences:** US$1.250bn becomes the central operational total-return planning value and the old US$45.7m result is superseded for total-return use. The low/high range is intentionally wide because the response horizon and future Women's impact are assumptions. The result is market-implied value, not audited profit or causal accounting value; exact net ROI still requires the all-in sponsorship and activation cost.
