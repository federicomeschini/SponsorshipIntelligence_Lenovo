# Componenti (snippet HTML/CSS standalone)

Questi file sono i **preview del DS** usati come riferimento di markup e classi.
Quando costruisci un kit, copia il markup pertinente e usa le classi/token già definiti
in `../colors_and_type.css`. NON reinventare componenti: parti da qui.

| File | Componente | Usato in |
|---|---|---|
| dashboard-kpi.html | KPI / stat card | analisi, dashboard |
| chart.html | contenitore grafico | analisi, dashboard |
| table.html | tabella dati | analisi, web report, dashboard |
| header.html | header/nav | tutti |
| chips.html | chip / eyebrow (pretitolo box lime) | tutti |
| type-headings.html | gerarchia titoli (H1 Hedvig … H3 Atkinson) | tutti |
